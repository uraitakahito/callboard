# callboard

castlist（アクターの台帳）と pagetray（ページの置き場）の画面をまとめるサーバー。castlist と pagetray は、Smithy の定義から作った client で API を通して使う。data は持たない。

作り始めた所（AI-32）。まだ release は無い。今あるのは、入口と、castlist から移したプロフィールと相関図。残りの画面は、これから 1 つずつ移す。
